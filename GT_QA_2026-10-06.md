## 4. Analisis waktu

- **Total:** waktu model 4.096 dtk, 177 panggilan, 316 ribu token keluaran, 64% di antaranya pikiran.
- **Rumus kasar:** waktu ≈ 3,6 dtk per panggilan + ±11 dtk per 1.000 token yang ditulis. Yang paling menentukan adalah
  jumlah token yang ditulis, bukan yang dibaca.
- **Penyebab terbesar:**

  | Penyebab | Dampak | Kode |
  |---|---|---|
  | Rantai mode 4 berjalan otomatis sampai riset dan usulan baru | q7 giliran 1 = 48% waktu model | M92 |
  | Jawaban ditulis ulang setelah penolakan | ±730 dtk (18%); di 05b ±1.018 dtk (14%) | M84–M88 |
  | Penyortir menjalankan analisis penuh untuk "BBRI" | 569 dtk | M97 |
  | Banyak langkah kecil mekanis | 52 panggilan kecil, rata-rata 6 dtk | EXEC-P5 |

- **Cache prompt:** panggilan pertama tiap run hanya 28% kena cache, padahal di dalam satu run 89% (M96). Sudah
  diperbaiki dengan EXEC-S.
