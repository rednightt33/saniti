Tombol filter di baris indikator Flow — usulan

45 indikator di menu (FL07, FL35, FL36 disembunyikan). Dengan tombol Broker (cakupan + kotak N): 27; kotak Top N saja: 7; Board: 40; Investor: 41; tanpa tombol: 4.

Aturan (diturunkan dari parameter registry, bukan daftar manual):

• Indikator dengan cakupan broker mendapat tombol Broker: All brokers / Selected / Top-N. Memilih Top-N memunculkan kotak N di sebelahnya; Selected memunculkan daftar kode broker. • Indikator dengan Top N tanpa cakupan (Bandar Balance, Concentration Top-N, FL42) mendapat kotak N. • Papan → tombol Board; jenis investor → tombol Investor (sama dengan Broker Inventory). • Parameter lain (hari rolling, baseline, satuan, garis acuan, Side, urutan Top-N) tetap di dialog ⚙. • Clear di tombol mana pun: garis hilang dan panel menulis "Choose at least one …" (sama dengan butir 3). • Indikator baru otomatis ikut aturan ini.
