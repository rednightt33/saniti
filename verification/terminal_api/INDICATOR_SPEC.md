# Terminal indicator specification (T1)

Generated by `scripts/terminal_indicator_spec.py`; do not edit by hand.

Inputs are final daily bars of one ticker in ascending date order (no gaps filled, no zero-filled prehistory). EMA-type averages are seeded with the SMA of their first n valid values; RMA uses alpha 1/n with the same seed. A value is null until its window is full; a zero denominator gives null unless the convention says otherwise. Calculations use the full stored history (price files from 2018) so recursive values match Feature 04.

## Parity tests the calculation module must pass

- `FEATURE_04` rows: equal to `Feature_04_Technical_Indicator` (and `_INDEX`) on the full history of BBCA, GOTO, IHSG and 20 random tickers (relative difference ≤ 1e-9, same first valid bar).
- `TA_LIB` rows: equal to TA-Lib 0.6.8 with the stated function and parameters on the same tickers.
- `HTML` rows: equal to the reference HTML engine (`03-terminal-right-panel.html`, lines 1733–2005) on the same tickers, except where this table states a different convention.
- Edge cases on synthetic bars: flat prices, zero volume, zero range (H=L), a single bar, a gap of missing bars.
