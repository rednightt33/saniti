## Method

- **Feature 01:** `refresh_feature_01_stock_intraday(timeframe, tickers, from)`.
  - It is the live `refresh_feature_01_stock_daily` (read 2026-10-31) with the bar key, one period = one bar.
  - Volatility is annualised with `sqrt(bars_per_year)`, where `bars_per_year` = round(252 × the mean IHSG bars of the
    COMPLETE sessions of the timeframe in `price_stock_idx_intraday_quality`). It is stored on every row.
  - Values derived 2026-10-31: 5m 16,017; 15m 5,652; 1h 1,766; 4h 504.
  - With a `from`, the 120 bars before it are read as context (the longest dependency, `volatility_60bar_change_pct`).
- **Feature 04:** `features/feature04/engine.py` and `incremental.py`, unchanged (the daily worker uses them).
  - They accept only daily dates, so each bar gets a synthetic date: the n-th weekday after 1970-01-05 for the n-th
    bar of its series. The engine reads only the order of its rows.
  - Backfill: `engine.calculate` (rows) plus `calculate_incremental(state_only=True)` (state).
  - Daily: the new bars from the stored state (`feature04_intraday_state`). A change at or before the last bar
    recalculates the series.
